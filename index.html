FLAGSHIPFYP / startup track · 2026

PTBox: Autonomous Pentest Drop-Box

An offline, AI-driven internal pentest appliance. Drop one small box (Jetson Orin Nano or laptop) on a network and it runs recon, enumeration, triage, exploitation, looting and privilege escalation, then writes a PDF report with no cloud dependency. A deterministic engine is ground truth; a locally fine-tuned Qwen2.5-3B (one QLoRA adapter per agent) runs the same ReAct loop on-device. Hard safety rails: CIDR scope-lock, HMAC-signed two-key arming per host, verify-before-fire, lockout-safe credential spraying. Verified end to end on Metasploitable2 with a root shell, loot and report.
